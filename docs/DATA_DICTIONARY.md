# Data Dictionary

Fields in the registry describe source material lots and demand records. Numeric readiness fields use a local 0–100 planning scale.

Key fields: `record_type` = SOURCE or DEMAND; `material_type` and `material_grade` describe compatibility; `quantity_tonnes` is source or required quantity; `available_date` and `demand_date` support timing; transport, storage, buyer, processing, contamination and carbon fields provide operational screening signals.
